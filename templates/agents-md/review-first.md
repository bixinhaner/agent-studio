# AGENTS.md Template: Review First

## Primary Goal
- Prioritize bug/risk discovery and regression prevention.
- Treat every change as potentially user-impacting.

## Review Checklist
1. Confirm behavior against requirements and edge cases.
2. Check null/empty/error branches and fallback behavior.
3. Verify data consistency across API, persistence, and UI.
4. Ensure tests cover critical paths.

## Output Style
- List findings by severity first.
- Include file and line references where possible.
- Keep summaries concise and actionable.
